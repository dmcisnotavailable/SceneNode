# SceneNode

**让长视频更容易浏览：AI 自动生成章节摘要，点击章节即可跳转到对应片段。**

## 项目背景

面对长篇访谈、综艺和其他对话类视频，用户往往没有时间完整观看，也难以快速定位自己感兴趣的内容。

SceneNote 希望通过语音识别和大语言模型，将长视频整理为带时间戳的章节，帮助用户快速了解内容结构，并直接跳转到感兴趣的片段。

## 核心功能

- **本地视频上传与播放**：支持 MP4 视频。
- **自动语音转写**：使用 FFmpeg 提取音频，通过 faster-whisper 生成带时间戳的文本。
- **AI 章节生成**：LLM 根据转写内容识别话题变化，生成章节标题和摘要。
- **章节定位**：点击章节即可跳转到视频对应位置。
- **异步处理状态**：上传后自动分析，前端通过轮询获取处理状态。

## 技术栈

- 前端：React、TypeScript、Vite
- 后端：Python、FastAPI
- 媒体处理：FFmpeg
- 语音识别：faster-whisper
- 章节生成：兼容 OpenAI API 的大语言模型
- 任务处理：FastAPI BackgroundTasks
- 数据存储：本地文件及 JSON

## 本地运行

### 1. 启动后端

```bash
cd backend
python -m venv .venv
```

Windows CMD 激活虚拟环境：

```cmd
.venv\Scripts\activate.bat
```

安装依赖：

```bash
python -m pip install -r requirements.txt
```

确保系统已安装 FFmpeg，并可通过命令行调用。

将 `.env.example` 复制为 `.env`，填写自己的模型 API 配置。

启动服务：

```bash
python -m uvicorn main:app --reload
```

### 2. 启动前端

在项目根目录执行：

```bash
npm install
npm run dev
```

打开终端显示的本地开发地址。

### 3. 使用方法

1. 选择本地 MP4 视频。
2. 等待系统完成音频提取、语音转写和章节生成。
3. 查看 AI 生成的章节标题与摘要。
4. 点击感兴趣的章节，跳转到对应视频位置。

## 当前限制

- 第一版主要分析语音内容，不支持完整的视觉剧情理解。
- 本地 CPU 转写长视频可能耗时较长。
- 后台任务不支持服务重启后的自动恢复。
- 暂不支持历史视频列表与刷新后的自动恢复。
- 章节生成质量受语音识别准确率和模型能力影响。
